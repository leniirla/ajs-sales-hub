# 📊 AJS Sales Hub — Enterprise Analytics & Management Platform

[![Node.js Version](https://img.shields.io/badge/Node.js-%3E%3D18.0.0-brightgreen)](https://nodejs.org)
[![React Version](https://img.shields.io/badge/React-18.x-61DAFB)](https://react.dev)

AJS Sales Hub is an enterprise-grade sales management, reporting, and analytics platform designed for high-throughput transaction processing, inventory tracking, and real-time revenue visualizer.

## 🌟 Key Features

- **Real-Time Analytics Dashboard**: Interactive charts showing sales velocity, conversion rates, and revenue metrics.
- **Inventory & Stock Tracking**: Automated low-stock alerts and order fulfillment workflows.
- **Role-Based Access Control (RBAC)**: Fine-grained user permissions for Admins, Sales Managers, and Field Representatives.
- **Automated Invoicing & Export**: PDF generation and CSV/Excel export capability for financial reporting.

## 🏗️ Architecture Stack

- **Frontend**: React 18, Tailwind CSS, Chart.js / Recharts
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL (Prisma ORM) / MongoDB
- **Authentication**: JWT & OAuth2 Session Management

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/leniirla/ajs-sales-hub.git

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env

# Start development server
npm run dev
```
